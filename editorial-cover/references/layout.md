# Layout · 版式

## 默认结构

```text
大标题
主体 / 产品 / 场景
一句副标题
```

信息密度低，阅读顺序清晰。

## 版式原型

### Top Giant Title

大标题占据顶部，主体从标题下方、侧边或字间进入画面。

### Negative Space Cover

利用墙面、天空、海面、窗边、建筑空区承载标题和情绪。

### Portrait + Type Lockup

人物和标题贴近、遮挡、错位或共轴，避免互不相干。

### Product Still Life

产品是主体，但通过光影、环境和文字关系形成 editorial 感。

### Architecture Frame

利用建筑的柱、墙、楼梯、阴影形成文字框架和人物站位。

### Motion Field

用运动模糊、风、布料、光线或色场制造一个视觉方向。

## 必须避免

```text
标题

主体

副标题
```

如果三者互不接触、互不影响，就是失败版式。
