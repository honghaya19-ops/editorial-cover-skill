# Cover Recipes · 封面配方

## 1. Quiet Lifestyle Portrait

适合：独处、慢生活、关系、自我、居住、日常仪式。

- 主体：一个人物，放松姿态，真实皮肤和自然表情
- 场景：窗边、房间、餐桌、街角、屋顶
- 字体：Editorial Serif + Small Sans
- 色彩：cream、warm gray、olive、charcoal
- 情绪：安静、亲密、松弛

## 2. Architectural Solitude

适合：城市、建筑、空间、秩序、孤独、现代性。

- 主体：一个人物或一个建筑空间
- 场景：混凝土、楼梯、天台、长廊、城市远景
- 字体：Editorial Serif 或 Thin Sans
- 色彩：concrete gray、cream、black、muted tan
- 情绪：冷静、秩序、疏离

## 3. Minimal Product Editorial

适合：电商广告、品牌视觉、产品主视觉。

- 主体：单个产品或产品 + 一个极简人物动作
- 场景：桌面、窗边、浴室、建筑阴影、柔和色场
- 字体：Editorial Serif / Bold Sans + Clean Sans
- 色彩：产品主色 + 奶油白 / 灰 / 黑
- 情绪：高级、安静、可信、有生活方式感

注意：不要做折扣促销、信息堆满或详情页风格。

## 4. Social Issue Editorial

适合：环保、城市更新、消费主义、身份、社会观察。

- 主体：一个清晰象征物或人物与环境冲突
- 场景：海洋、旧街区、城市、公共空间
- 字体：Bold Sans 或 Serif
- 色彩：低饱和，但对比明确
- 情绪：警醒、克制、悲悯、张力

## 5. Futurist Beauty / Tech

适合：AI、身份、皮肤、身体、未来、模型、数据。

- 主体：面部、身体局部、科技材质、界面式线条
- 场景：干净冷色背景或实验室式空间
- 字体：Thin Futurist Sans / Outline Sans
- 色彩：cool blue gray、skin tone、white、silver
- 情绪：冷静、疏离、未来感

## 6. Motion / Drift

适合：运动、速度、变化、迁移、流动、坚持。

- 主体：骑行、行走、奔跑、转身或静止人物
- 场景：城市街道、隧道、运动场、光影通道
- 字体：Bold Sans 或大 Serif
- 色彩：black、cream、orange、deep teal
- 情绪：坚定、孤独、向前、游离

## 7. Social Platform Editorial

适合：社媒、平台、代际差异、信息流、注意力、公共舆论。

- 主体：人物与抽象界面、公共广告牌、信息流装置、纸媒或屏幕形成对照
- 场景：地铁、走廊、候车厅、办公室、街头橱窗
- 字体：Bold Sans / Sharp Serif + restrained italic tagline
- 色彩：deep green、charcoal、off-white、cool gray、small warm accent
- 情绪：冷静、观察、摩擦、有观点

注意：使用虚构 UI 和不可读信息，避免真实平台 logo、真实账号和仿真新闻证据。

## 8. Beauty / Wellness Cover

适合：护肤、美妆、身体照护、健康、安静商业视觉。

- 主体：面部、手、产品、玻璃、镜面、水汽、柔和皮肤质感
- 场景：干净影棚、窗边、浴室、淡色背景、极简桌面
- 字体：Elegant Serif / Clean Sans / Thin Sans
- 色彩：powder blue、ivory、skin tone、silver、soft green
- 情绪：干净、柔和、可信、克制

注意：避免过度磨皮、塑料皮肤、性化姿态和廉价美妆广告感。
